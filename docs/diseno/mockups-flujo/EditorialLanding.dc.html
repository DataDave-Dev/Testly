PROYECTO ESCOLAR · FIME 2026

Pega tu código. Recibe pruebas unitarias — con el porqué de cada caso.

Testly no solo genera el archivo de prueba: te explica por qué se eligió cada caso, para que la próxima vez sepas escribirlas tú.

Ver un ejemplo
def dividir(a, b): if b == 0: raise ValueError("no se puede dividir entre 0") return a / b
TESTS GENERADOS

test_dividir_normal — caso feliz: división válida entre dos enteros.

test_dividir_entre_cero — caso límite: verifica que se lanza ValueError.

①
Explica el criterio
Cada caso viene con la razón por la que se eligió: qué cubre y qué podría romperse ahí.
②
Enseña, no reemplaza
La meta es que después de un par de usos sepas escribir tus propias pruebas sin la herramienta.
③
Sin ejecutar en servidor
Tu código nunca corre del lado del servidor. La verificación es por reglas, no por ejecución.
